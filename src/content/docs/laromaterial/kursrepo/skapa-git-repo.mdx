Nu skall du skapa kursens git repo, lokalt i din terminal under katalogen `dbwebb-kurser`, och koppla det till den plats för repot som du nyligen skapade på GitHub.

## Gå till katalogen dbwebb-kurser

Börja med att gå till din arbetskatalog för kurserna, den som du döpte till `dbwebb-kurser`.

```bash title="Gå till katalogen dbwebb-kurser"
# Gå till hemmakatalogen
cd

# Gå till dbwebb-kurser
cd dbwebb-kurser
```

Du kan göra samma sak i ett kommando och här refererar `~` till din hemmakatalog.

```bash title="Gå till katalogen dbwebb-kurser, i ett kommando"
cd ~/dbwebb-kurser
```

Använd kommandot `pwd` och `ls` för att försäkra dig om att du är på rätt plats i filsystemet.

## Klona ditt GitHub repo till ett lokalt repo

Logga in på [GitHub](https://github.com) där ska du ha fått ett kursrepo som heter python-xxxx## där xxxx## är ditt studentkonto med fyra tecken och två siffror, tex abcd25 eller motsvarande.

Det är bara du själv och lärarna i kursen som har tillgång till ditt kursrepo.

Nu ska vi skapa en lokal kopia av ditt GitHub repo genom att klicka på knappen "Code" och kopiera SSH-länken.

```bash title="Kommandon för att klona ditt kursrepo"
git clone git@github.com:bth-python/python-<akronym>.git
```

Om din akronym är `abcd25` så ser kommandot ut så här:  
`git clone git@github.com:bth-python/python-abcd25.git`

### Kolla i ditt lokala Git-repo

Du kan använda kommandot `pwd` och `ls` för att kontrollera vilken katalog du är i och vad den innehåller. Använder du `ls -la` får får du detaljer om filer och kataloger och det visas även dolda kataloger som börjar med en punkt `.`. För att byta katalog använder du kommandot `cd python-abcd25` om akronymen är abcd25.

Så här ser det ut i ditt Git-repo ut i terminalen:

### Kör setup i ditt lokala Git-repo

Nu kan du köra följande kommando för att göra ditt kursrepo redo. Kommandot skapar kataloger, laddar ner workflow-fil & task-fil samt tester. Dessutom skapas första inlämningsbranchen `bth/submit/kmom03`.

```bash title="Kommando för att göra ditt lokala kursrepo redo"
pwd # visar att du står i ditt lokala repo dbwebb-kurser/python-abcd25 för studenten abcd25

task setup
```

I slutet av setup-skriptet körs en del tester. Vid eventuella fel så kör du de kommandon som föreslås. 

**Kör om `task setup` tills alla tester går igenom.**

När alla testerna gått igenom är det bara att köra på! Så här ser det ut i din terminal när `task setup` gått igenom:
