För att kunna arbeta med kursens kod och uppgifter på GitHub behöver du koppla ditt GitHub-konto till kursens organisation.

På kursens [Canvas](https://canvas.bth.se) sida finns en uppgift som heter **GitHub invite**. Gå till den, följ instruktionerna där och lämna in uppgiften.

När uppgiften har rättats får du en inbjudan till organisationen. Efter några minuter får du en notis i Canvas och ett mejl till den GitHub-användare du angav i uppgiften. Uppgiften är godkänd när du fått omdömet **0(G)**. G står för godkänt (nollan för 0 poäng).

När du har fått inbjudan kan du acceptera den genom att klicka på länken i mejlet eller i Canvas. Vi rekommenderar att du använder kommentaren i Canvas som du hittar under "Omdöme". Längst ut till höger finns en symbol med en pratbubbla, klicka på den för att se kommentarna. Ett annat sätt är att klicka på "Uppgifter" i Canvas och klicka på knappen "Visa feedback" uppe till höger. Där hittar du länkar till både inbjudan och ditt repo.

:::note
Vi lärare får inga notiser om ni gör kommentarer i Canvas och missar därför de flesta studentkommentarer i Canvas.
:::

## Aktivera Single Sign-On (SSO)

:::note
Om knappen `Single Sign-On` inte visas, kontrollera att du har genomfört Canvasuppgiften GitHub invite och accepterat inbjudan. Om knappen fortfarande inte visas, [kontakta IT Helpdesk](https://www.bth.se/om-bth/kontakta-oss/it-helpdesk) och ange din studentmejladress (samma adress som du använde i GitHub invite) samt kurskoden DV1670.
:::

När du har accepterat inbjudan till organisationen behöver du aktivera Single Sign-On (SSO) för att kunna arbeta med kursens kod och uppgifter. Klicka på knappen `Single Sign-On` uppe till höger på sidan i organisationen.
