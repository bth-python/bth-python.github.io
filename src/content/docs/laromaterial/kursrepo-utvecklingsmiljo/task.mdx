Task är ett byggverktyg och "task runner". Det är ett verktyg som förenklar processen att köra olika kommandon i terminalen. Det är ett verktyg som kan hjälpa oss att automatisera uppgifter som vi annars skulle behöva skriva in manuellt varje gång. Du kan läsa mer på dess [webbplats](https://taskfile.dev/).

Vi ska främst använda det för att förenkla att ladda ner olika filer i kursen.


## Kör task

Du kan kolla vilka kommandon som finns med följande kommando.

```console title="Lista kommandon i Taskfile."
uv run task --list
```

`uv run task` är kommandot för att köra Task och `--list` är en flagga som listar alla kommandon som finns i Taskfile.

Det finns följande kommandon tillgängliga:

```
task: Available tasks for this project:
* check-ready:                Check if assignment is ready for submission. Usage: 'task check-ready -- kmom01'
* check-repo-setup:           Checks that repo contain all needed files and is setup correctly.
* create-src-dirs:            Creates the src directory structure if they do not exist
* download-all:               Download all files available config files
* download-extensions:        Download file with recommended extensions.
* download-hooks:             Download git hook files from the template repository and install them
* download-lab:               Download a lab. Run with 'uv run task download-lab -- lab_XX', replace XX with the lab number.
* download-ruff-config:       Downloads the ruff configuration file from the artifact repository
* download-taskfile:          Downloads the Taskfile from the artifact repository
* download-tests:             Replaces files in tests/ with files from the artifact repository, https://github.com/bth-python/template
* download-workflow:          Download workflows file that checks code at pull request.
* setup:                      Initial setup - run all configuration downloads
* test:                       Run tests for a given kmom from any directory. Usage: 'task test -- kmom04'
```

Alla kommandon startar med `uv run task`. Du kan testa om inlämningsuppgiften till kmom01 är klar.

```console title="Testa om kmom01 är klart."
uv run task check-ready -- kmom01
```

Det ger naturligtvis fel eftersom du inte gjort inlämningsuppgiften till kmom01 än.

Bra då har vi koll på verktyget task.
