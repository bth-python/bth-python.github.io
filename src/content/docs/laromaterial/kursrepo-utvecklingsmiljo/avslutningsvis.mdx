Då är vi klara med att installera den delen av utvecklingsmiljön som hjälper dig att komma igång med kursens första kmom.

## Verifiera ditt repo

Om du vill kontrollera om ditt repo är rätt uppsatt så kör du:

```console title="Testa om ditt repo är ok."
uv run task check-repo-setup
```

Här bör alla tester gå igenom, precis som de gjorde när du körde `task setup` efter att du klonat ditt repo på GitHub.

Du kan också kolla på din commit-historiken med `git log` att du har commits med all kod. Där bör du hitta committen "Update the file README with info about me" när du uppdaterade README.md för att lägga till på GitHub. Du bör även hitta committen du gjorde när du fixade extension i VS Code.


## Verifiera kopplingen till Canvas

Nu när vi har installerat utvecklingsmiljön så ska vi också verifiera att den är kopplad till Canvas.

Gå till ditt repo på GitHub och klicka på `Pull request` följt av `New Pull Request`.

Alla filer du har skapat finns bara på `main` branchen. Med Pull request kan vi kopiera den koden till en annan branch. Nu ska du välja vilken branch du ska kopiera den till.

Välj branch `bth/submit/test-gitconfig` genom att klicka på knappen med `base:main` (1) och välja branchen  `bth/submit/test-gitconfig` (2).

Nu kan du se alla de commits och dess data som ska flyttas till `bth/submit/test-gitconfig` branchen. Klicka på `Create pull request`.

Ge din PR en titel, exempelvis "Test connection", och klicka sen igen på `Create pull request`.

import test5ny from '@assets/kursrepo-utvecklingsmiljo/test5ny.png';

<Figure 
    src={test5ny}
    caption="Välj en titel och skapa PR."
/>

Nu har din PR skapats. Skrolla ner på sidan så borde du se något som bilden nedanför. Du kanske behöver ladda om sidan för att det ska synas. Efter några sekunder eller någon minut (det varierar hur lång tid det tar) ska det stå `All checks have passed`. Om det inte gör det har något gått fel. Det är svårt att säga vad av allt som kan gått fel. Du kan klicka på den knappen och tas till fel utskriften, du kan försöka tolka det för se vad som gått fel, annars kontakta en lärare för hjälp.

import test6ny from '@assets/kursrepo-utvecklingsmiljo/test6ny.png';

<Figure

Om allt har gått bra ska du automatiskt ha fått ett betyg på uppgiften `Test gitconfig` i Canvas. Gå till Canvas sidan för kursen och kolla om du har fått ett betyg och en kommentar på den uppgiften. Klicka på kommentartecknet för att läsa kommentaren.

Om du inte har fått betyg `G` och en kommentar har något gått fel, kontakta en lärare.

Avsluta med att gå tillbaka till din pull request och avsluta den. Klicka på `Close pull request`.

Bra jobbat, nu är du klar med utvecklingsmiljön.



## Vanliga fel

### There isn’t anything to compare.

När du ska skapa en PR mot bth/submit/test-gitconfig får du inte skapa den för att `bth/submit/test-gitconfig and main are entirely different commit histories.`.

import errorImage from '@assets/kursrepo-utvecklingsmiljo/end-pr-error.png';

<Figure 
    src={errorImage}
    caption="Går inte att skapa PR."
/>

Då gör du bara en ny ändring i ditt lokala git repo. Du kan till exempel uppdatera `README.md` och pusha ändringarna, se [Uppdatera fil i git repot](../gitadd) om du behöver hjälp med kommandona.

#### Försök skapa en PR
