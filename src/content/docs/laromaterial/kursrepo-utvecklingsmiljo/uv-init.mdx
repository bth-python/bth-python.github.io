När vi jobbar i projekt som har att göra med programmeringsspråket Python så kan vi använda `uv` som ett sätt att hantera projektet och installera verktyg och extra kodmoduler och hjälpverktyg vid behov. Det finns en virtuell miljö redan i ditt repo.

Följande filer tillhör uv:
- `.python-version` - en fil som innehåller vilken version av Python som skall användas i projektet.
- `pyproject.toml` - en fil som innehåller inställningar för projektet och eventuella beroenden (dependencies).
- `uv.lock` - en fil som innehåller alla extra verktyg/moduler/paket som är installerade i projektet och vilken version de har.
- `.venv` - en katalog som innehåller en virtuell miljö för Python, där alla moduler installeras lokalt för projektet. Den ska inte vara en del av repot och därför har vi lagt till den i `.gitignore`. Den katalogen kan alltid återskapas utifrån informationen i `uv.lock` när du kör den virtuella miljön via kommandot `uv run main.py`.


## Verifiera ditt uv projekt

Vi börjar med kommandot `uv version` för att se att uv är installerat.

```bash title="Kontrollera att uv är installerat."
uv version # ger utskriften python-abcd25 0.1.0
```

Om du vill ha ditt eget repos namn så uppdaterar du filen `pyproject.toml` och byter ut python-abcd25 mot ditt repos namn. Glöm inte att göra add, commit och push på dina ändringar innan du testar `uv version igen`. Men det spelar ingen roll om det står python-abcd25.

Skapa en fil `main.py` med `touch main.py` eller skapa den direkt i VS Code med "File-> New Text File". Editera den i VS Code med följande:

```bash title="Innehåll i main.py"
def main():
    print("Hello from bth-python!")

if __name__ == "__main__":
    main()
```

Testa exekvera `main.py` för att se att allt fungerar som det skall.

```bash title="Exekvera main.py"
uv run main.py # ger utskriften Hello from bth-python!
```

Det kommer att skapa en katalog `.venv` där alla verktyg och moduler installeras lokalt för projektet.

Nu när allt funkar ska vi radera `main.py`. Vi ska skapa andra filer och kataloger senare.

```bash title="Radera main.py"
rm main.py
```
