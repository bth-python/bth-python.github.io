File `.gitignore` används till att bestämma vilka filnamn och kataloger som inte skall vara en del av repot, det är alltså filer som vi inte vill checka in i repot. Filer vi inte vill checka in kan innehålla känslig information, till exempel lösenord. Eller så är det filer och kataloger som genereras och skapas när vi installerar eller kör några av programmen, eller så kan det vara filer som är specifika för ett visst operativsystem som inte skall vara en del av ett repo.

:::note
Inget ska uppdateras, detta är bara en förklaring av innehållet i filen `.gitignore`.
:::


## Innehåll filen .gitignore

Denna .gitignore-fil ser till att tillfälliga filer, virtuella Python-miljöer, cachefiler och operativsystemspecifika filer inte sparas i Git-repot. På så sätt undviks onödiga filer och repot hålls rent och lättare att samarbeta kring.

```bash title="Utkast till en .gitignore fil."
# python
__pycache__/
*.py[codz]
*$py.class

# Environments
.venv
venv/
venv.bak/

# Ruff stuff:
.ruff_cache/

# macOS
.DS_Store
.AppleDouble
.LSOverride
```

Om du längre fram i kursen kommer på andra filer som behöver exkluderas från git repot så kan du bara placera de katalog- och filnamnen i din `.gitignore` fil.
