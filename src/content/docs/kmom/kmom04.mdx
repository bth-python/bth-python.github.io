## Intro till listor

En lista är som en låda med fack. Varje fack har ett nummer (index) och innehåller ett element (ett värde). Vi kan ändra på innehållet i listan och vi kan ta reda på vad som finns i ett visst fack.

:::tip
När du ska jobba med kursen är det lättast om du öppnar VS Code från terminalen innan du börjar jobba.

```bash
cd dbwebb-kurser/python-<din akronym>
code .
```

Använd `practice` mappen i kmom04-katalogen för att skriva övningskod.
:::
